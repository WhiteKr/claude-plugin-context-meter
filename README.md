# context-meter

Claude Code 입력창에 한 줄짜리 미터를 그리는 플러그인입니다.
콘텍스트가 응답 품질이 떨어지는 구간에 들어갔는지, 사용량 한도가 얼마나 남았는지를 보여 줍니다.

## 설치

터미널 세션의 입력창에서 다음을 입력합니다.

```
/plugin install context-meter --marketplace WhiteKr/claude-context-meter
```

`Add marketplace?`에 `y`로 답하고 설치 범위를 고릅니다.

셸에서 설치하려면 다음을 실행합니다.

```bash
claude plugin install context-meter --marketplace WhiteKr/claude-context-meter
```

## 기능

- 콘텍스트 토큰 수와 현재 구간을 보여 줍니다.
- 5시간 한도, 7일 한도, 지출 한도의 사용률과 리셋까지 남은 시간을 보여 줍니다.
- 지금 속도로 다음 구간, 자동 압축, 한도 소진까지 얼마나 남았는지 예측합니다.
- 저하 구간에 들어가거나 한도가 바닥나 가면 토스트로 알립니다.
- `▴`를 누르면 콘텍스트를 많이 차지하는 항목과 **지금 압축** 버튼이 있는 패널을 엽니다.

## 콘텍스트 구간

| 구간 | 토큰 수 |
| --- | --- |
| `최적` | 100k 미만 |
| `양호` | 256k 미만 |
| `저하 시작` | 512k 미만 |
| `뚜렷한 저하` | 512k 이상 |

콘텍스트 윈도우가 이보다 작으면 경계를 윈도우 크기에 맞게 줄입니다.
경계 값은 Opus 4.6과 4.7의 MRCR v2 결과와 context rot 연구에서 가져온 추정치입니다.
